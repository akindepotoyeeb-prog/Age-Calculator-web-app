# 🎂 AgeCalculator

A feature-rich, beautiful, and interactive Age Calculator web app built with pure HTML, CSS, and JavaScript. 

## ✨ Features
* **Precise Age Breakdown:** Calculates exact age down to the years, months, and days, plus total months and total days lived.
* **Live Birthday Countdown:** Real-time ticking timer (Days, Hours, Minutes, Seconds) counting down to your next birthday.
* **Day of Birth:** Displays the exact day of the week you were born (e.g., Saturday).
* **Dual Zodiac Insights:** 
  * ♈ **Western Zodiac:** Birth month & day star sign with personality traits.
  * 🐉 **Chinese Zodiac:** Birth year animal from the 12-year cycle with character traits.
* **100% Client-Side:** Runs entirely in the browser with no sign-ups or server dependencies required.

## 🛠️ Built With
* **HTML5** (Structured semantic markup)
* **CSS3** (Custom variables, glassmorphism, responsive grid layouts, and Google Fonts)
* **JavaScript (ES6+)** (Date manipulation, calendar validation, and real-time interval tickers)

## 🚀 How to Run Locally
1. Clone this repository or download the ZIP files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser or run it using VS Code Live Server.
